# Internationalization (i18n)

## Architecture

Vibe uses a custom i18n system built on:
- JSON translation resources organized by language and namespace
- Client-side React context provider for locale management
- Server-side translation engine with fallback support
- Lazy-loaded translation namespaces
- TypeScript-first design with full type safety

## Directory Structure

## Usage

### In React Components

```tsx
import { useTranslation } from "@/lib/i18n/useTranslation";

function MyComponent() {
  const { t, tp, locale } = useTranslation("common");

  return (
    <div>
      <h1>{t("appName")}</h1>
      <p>{t("welcome", { name: user.displayName })}</p>
      <p>{tp("1 item", "{count} items", items.length)}</p>
    </div>
  );
}
```

### Using the T Component

```tsx
import { T, TPlural } from "@/components/t";

function MyComponent() {
  return (
    <div>
      <T k="appName" />
      <T k="welcome" ns="common" params={{ name: "User" }} />
      <TPlural singular="1 like" plural="{count} likes" count={5} />
    </div>
  );
}
```

## Language Detection

Priority order:
1. Explicit user selection (via LanguageSelector)
2. Saved preference (localStorage `vibe_language`)
3. Telegram client locale (`Telegram.WebApp.initDataUnsafe.user.language_code`)
4. Browser locale (`navigator.language`)
5. Default (English)

## RTL Support

Arabic is the primary RTL language. The system supports:
- Dynamic `dir` attribute on `<html>` element
- RTL-aware CSS classes and inline styles via `useRtl()` hook
- Flipped icons and transforms for directional UI elements
- Bidirectional text handling for mixed-language content

## Translation Workflow

1. Add keys to English JSON files (source of truth)
2. Create/update translation files for target languages
3. Use the Admin Translation Manager (`/admin/translations`) to manage translations
4. Validate translations before publishing
5. Publish to make visible to users

## Performance

- Translation namespaces are lazy-loaded on demand
- Initial load: common, navigation, errors, time namespaces
- Translations are cached in memory with 5-minute TTL
- Each language's resources are separate files (no monolithic bundle)
